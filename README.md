# GEMWARD

เกม Tower Defense พร้อมชื่อผู้เล่นและอันดับออนไลน์ทดลอง

## เปิดเล่นผ่าน GitHub Pages

1. อัปโหลดไฟล์ในโฟลเดอร์นี้เข้า root ของ xjon12345/GEMWARD (อัปโหลด index.html โดยตรง ไม่ต้องอัปโหลด ZIP)
2. ไปที่ Settings → Pages
3. Source เลือก Deploy from a branch
4. เลือก branch main และ /(root) แล้ว Save
5. รอ GitHub เผยแพร่ แล้วใช้ลิงก์ที่ GitHub แสดง

ลิงก์ที่คาดว่าจะใช้: https://xjon12345.github.io/GEMWARD/ — ต้องเปิด Pages ก่อนจึงจะเล่นได้

## ระบบคะแนน

เกมติดต่อฐานข้อมูลออนไลน์ผ่าน https://gemward-pixel-td-sixsaw.reginaldwyatt1665.chatgpt.site โดยไม่ต้องใส่ API key ผู้เล่นตั้งชื่อก่อนเริ่ม เลือกเล่นในเครื่องได้ และเริ่มติดอันดับเมื่อผ่านเวฟ 21 อันดับแยกตามความยาก กติกา grove-v12

ชื่อเป็นสาธารณะ ผู้เล่นจำด้วยรหัสในเบราว์เซอร์ ล้างข้อมูลหรือเปลี่ยนเครื่องจะเป็นผู้เล่นใหม่ รันเสกเงิน/อมตะไม่แสดงในอันดับ

อันดับนี้ตรวจข้อมูลเบื้องต้น ยังไม่จำลองการต่อสู้ซ้ำ จึงไม่เหมาะกับการแข่งขันชิงรางวัล

คำสั่งเจ้าของใช้ที่เว็บหลักเท่านั้น ห้ามอัปโหลดกุญแจ Console หรือไฟล์ .env ขึ้น GitHub

## อัปเดตมอนสเตอร์ v11
ภาพวาดใหม่ครบ 12 ชนิดให้เข้ากับป้อม เพิ่มเต่าป้อมศิลา วิญญาณพฤกษา ซาลาแมนเดอร์เถ้า กวางเหมันต์ และรังหน่อไม้ม่วง เปิดสมุดมอนสเตอร์ด้วยไอคอนมุมบนขวาเพื่ออ่านจุดอ่อน


## อัปเดต v12
แก้ Auto/วงระยะค้าง คลิกป้อมเปิดอัปเกรด เลือกเป้าหมาย 9 แบบ Node เริ่ม 0 แต้ม ได้ 1 แต้มทุก 35 สังหาร ถนนหินมอสใหม่ แปลนแสดงภาพป้อม ซ่อน HUD ระหว่างวาง กด F2 เปิด–ปิด UI เก็บค่าปรับสมดุลจากการอัปโหลดเดิมไว้แล้ว

## โรงหลอมผู้พิทักษ์ v13
หน้าจัดการป้อมใหม่ พร้อมกรอบไม้และทองแกะสลัก เถาวัลย์ ภาพป้อมขนาดใหญ่ และ Gem 12 ภาพต่างทรง แสดงทั้งคลังอัญมณีและช่องติดตั้ง รองรับมือถือ ระบบคะแนนยังใช้ grove-v12

## อนิเมชั่น v14
ตั้งค่า → อนิเมชั่นป้อม → ตามเครื่อง / เปิดเต็ม / ปิด เลือกเปิดเต็มเพื่อใช้อนิเมชั่นแม้เครื่องเปิดลดการเคลื่อนไหว บันทึกตัวเลือกบนเบราว์เซอร์ อนิเมชั่นสนามหยุดระหว่างพักเกมและเปิดเมนู รูปในหน้าจัดการเป็นภาพนิ่ง คะแนนยังใช้ grove-v12

## จารึกพลัง v15
UI Node ใหม่พร้อมตราภาพ 20 สาย คำอธิบายและตัวอย่างตัวเลขครบ 220 จุด รูปป้อมที่ได้รับผล เงื่อนไข Gem/Relic/สถานะ ค้นหาด้วยชื่อป้อมได้ ทุกหน้าที่ใช้ทองและตอนวางป้อมแสดงยอดทองคงเหลือสด ระบบคะแนนยังใช้ grove-v12
