# GEMWARD

เล่นเกม: https://xjon12345.github.io/GEMWARD/

Tower Defense ในป่าคริสตัล พร้อม Gem, 600 โหนด, Relic, สัตว์เลี้ยง และโหมด Endless

เวอร์ชัน 45 เพิ่มกราฟิก VFX คลาส 3 ทั้ง 16 สาย พร้อมดาเมจที่ปรับเพิ่มจากเวอร์ชัน 44 ปลดล็อกอัปเกรดคลาส 3 ที่เวฟ 45 ราคา 4,200 ทองต่อป้อม

GitHub Pages ให้บริการตัวเกม ส่วนบัญชี ID/รหัสผ่าน เซฟข้ามเครื่อง สัตว์เลี้ยง และอันดับออนไลน์ใช้หลังบ้านเดิมที่ https://gemward-pixel-td-sixsaw.reginaldwyatt1665.chatgpt.site ระบบคะแนนและข้อมูลผู้เล่นเดิมยังคงอยู่ การใช้คำสั่ง GM จะทำให้รันนั้นไม่เข้าร่วมอันดับ

ไฟล์เกมหลักคือ index.html และเพลงอยู่ใน assets/music/ เปิด GitHub Pages จากสาขา main ที่โฟลเดอร์ราก ไม่มีรหัสลับหรือไฟล์ตั้งค่าหลังบ้านใน Repository นี้
